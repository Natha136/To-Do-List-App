# 📋 To-Do List

A simple and colorful Android To-Do List application developed using **Java** in **Android Studio**. This application helps users organize daily tasks with a clean pastel-themed interface and useful productivity features.

---

## ✨ Features

- 📌 Create new tasks
- 📝 Edit existing tasks
- 🗑 Delete tasks
- ✅ Mark tasks as completed
- 📖 View task details
- 🔍 Real-time search by title
- 📂 Sort tasks by:
  - Title
  - Deadline
  - Created Date
- 🔔 Daily reminder notifications
- 🎨 Pastel-themed modern UI
- 📱 Responsive layout
- 💾 Local data storage using Room Database

## 🚀 Getting Started

### Requirements

- Android Studio
- Android SDK 24+
- Java 8 or higher

### Installation

1. Clone this repository.

```bash
git clone https://github.com/your-username/to-do-list.git
```

2. Open the project in Android Studio.

3. Sync Gradle.

4. Run the application on an emulator or Android device.
